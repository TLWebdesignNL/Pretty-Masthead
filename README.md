# Pretty Masthead
Pretty Masthead module for Joomla 5.4 and Joomla 6.

Shows a full-width masthead image with a title, and optionally a description and a button. Set a default masthead, add mastheads for specific menu items, and let articles use their own title and image.

## Requirements
- Joomla 5.4 or Joomla 6
- PHP 8.1 or newer (Joomla 6 itself requires PHP 8.3)
